# Campus ERP / SIAKAD Universitas — PRD v1.0

Dokumen ini adalah ringkasan produk dari requirement Campus ERP: platform universitas multi-kampus yang menghubungkan PMB, mahasiswa, akademik, KRS, presensi, nilai, keuangan, layanan mahasiswa, dan pelaporan.

## MVP saat ini

MVP mengutamakan fondasi yang menjaga correctness: organization hierarchy, ULID database, user/role/scope, curriculum, course offering, class section, KRS approved, attendance session, grade scale, invoice/payment allocation, audit-ready models, dashboard per-role, portal mahasiswa, docs, API v1, sitemap, blog, dan scheduler.

## Fase berikutnya

PMB end-to-end, LMS/CBT, scholarship/leave, MBKM/magang/KKN, thesis/yudisium/wisuda/alumni, library/research/community service, HRM/procurement/asset/accounting, integration PDDikti, dan AI enhancement. Fitur yang belum memiliki lifecycle, policy, test, dan UI tidak dianggap selesai.
